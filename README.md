Научно-исследовательский проект (магистерская диссертация, МГТУ им. Н.Э. Баумана), посвященный созданию цифровой библиотеки с интеграцией платформы arXiv, дообучением трансформеров для семантического поиска и глубоким бенчмаркингом СУБД на больших объемах данных.

Ключевые результаты и этапы исследования:
•	Data Engineering и дообучение моделей: Самостоятельно провела разметку учебной выборки научных статей из репозитория arXiv. На этих данных дообучила модель SBERT (all-mpnet-base-v2) для реализации сценария семантического поиска (когда пользователь не знает точных реквизитов и ищет статью по смыслу проблемы или теме, в том числе с некорректным вводом).
•	Оценка качества ИИ:** На контрольной выборке проверила качество модели, рассчитав косинусное сходство и метрику MSE. Провела полный аудит классических метрик классификации для оценки релевантности и точности семантического поиска: Accuracy: 0.7236, Precision: 0.4067, Recall: 0.6375, F1-мера: 0.4966 (время ответа системы в данном сценарии составило стабильно менее 1 минуты).
•	Бенчмаркинг СУБД и оптимизация SLA (70 млн записей): Провела сравнительный анализ производительности и времени выполнения запросов в двух СУБД — PostgreSQL (индексы B-tree) и MongoDB (индексы B+tree). Изучила особенности структур данных и их влияние на latency при масштабировании базы до 70 000 000 записей.
•	Эргономическое разделение нагрузок: На основе оптимизации индексов СУБД обеспечила выполнение жесткого критерия SLA — время ответа системы не более 1.5 секунд при стандартных поисковых запросах пользователя по полям автора и названия статьи. Интеграция с внешними платформами: Реализовала интеграцию системы с API платформы arXiv для автоматического расширения базы знаний библиотеки.

Технологический стек:
•	AI & NLP: Sentence-BERT (SBERT), PyTorch, Hugging Face Transformers, Косинусное сходство, MSE.
•	Databases: PostgreSQL (B-tree), MongoDB (B+tree), Оптимизация больших данных (>70M записей).
•	API & Integrations: arXiv API, Python.
•	Архитектура: Проектирование ПО, UML-диаграммы (более 15 структурных и поведенческих схем).
